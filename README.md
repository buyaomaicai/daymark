# Daymark

Daymark 是一个面向单台 Windows 电脑的本地待办工具，基于 PySide6 和 QFluentWidgets。支持普通任务、每日任务、截止任务提醒、Windows 通知、系统托盘驻留和开机启动。Windows 11 上使用 DWM Acrylic 模糊客户区背景。

## 启动

需要 Windows 10/11 和 Python 3.10 或更新版本。在此目录打开终端运行：

```powershell
py -3 -m pip install -r requirements.txt
py -3 main.py
```

也可以双击 `run.bat`。首次运行后，数据保存在 `%LOCALAPPDATA%\Daymark\tasks.sqlite3`。

关闭主窗口或点击“最小化到托盘”会隐藏主窗口，Daymark 继续在 Windows 通知区域运行。托盘图标右键菜单可重新打开窗口或退出程序；如果图标未直接显示，请查看任务栏通知区域的隐藏图标。点击“开机启动”会在 Windows 当前用户的启动文件夹添加或移除启动项。

截止任务可通过日历选择日期、下拉选择时间，并在创建后按所设间隔提醒，至截止时间停止。普通任务不设置截止时间，也不发送提醒。若系统休眠或程序退出期间错过了提醒，程序恢复时只补发一次，再从恢复时间开始计算下一间隔。已过截止时间的任务会保存为逾期状态且不发送提醒。每日任务每天重置完成状态，不发送提醒。

## 当前范围

本版本面向单台 Windows 电脑本地使用。悬浮窗尚未实现；需要应用运行时才能检查提醒，Windows 登录后可通过开机启动自动运行。
